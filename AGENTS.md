## Cursor Cloud specific instructions

Este repositorio documenta el uso de SLM en Cursor. No incluye aún una aplicación ejecutable ni manifiestos de dependencias.

- El script de actualización de Cursor Cloud puede ser `true` hasta que existan dependencias instalables.
- No hay servicios que arrancar para pruebas de extremo a extremo.
- Los comandos estándar de lint, test, build y servidor de desarrollo no están definidos hasta que se añada el código del proyecto. Revisa `README.md` y cualquier `package.json` futuro antes de asumir comandos.
