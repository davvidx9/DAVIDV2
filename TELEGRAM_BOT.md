# Telegram Bot — /chk card checker

## 1) Creer bot f Telegram

1. Fta7 Telegram → chouf **@BotFather**
2. Sift `/newbot`
3. Smi w username l bot
4. Copier **token** li 3tak

## 2) Config

```bash
copy bot_config.json.example bot_config.json
```

Fta7 `bot_config.json` w 7ot token:

```json
{
  "telegram_bot_token": "123456:ABC-DEF..."
}
```

## 3) Cookies

Paste cookies f `cookies.json` (nfs talimt dial run.bat)

## 4) Lancer bot

Double-click **`run_bot.bat`**

## 5) Sift commande f Telegram

```
/chk card: 5294153155207609
month: 4
year: 2027
cvc2: 896
```
