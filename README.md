# SLM CURSOR

Proyecto de referencia para trabajar con **modelos de lenguaje pequeños (SLM)** dentro de [Cursor](https://cursor.com).

## Contenido

| Recurso | Descripción |
|--------|-------------|
| [docs/SLM-CURSOR.md](docs/SLM-CURSOR.md) | Guía: qué es un SLM, modelos en Cursor y cuándo usarlos |
| [AGENTS.md](AGENTS.md) | Instrucciones para agentes en Cursor Cloud |

## Estado del repositorio

Por ahora no hay aplicación ejecutable ni manifiesto de dependencias. El `.gitignore` está preparado para un futuro proyecto Angular/Node. Cuando añadas código, actualiza `AGENTS.md` con los comandos reales de lint, test y desarrollo.

## Inicio rápido

1. Abre el repositorio en Cursor.
2. Lee [docs/SLM-CURSOR.md](docs/SLM-CURSOR.md) para elegir el modo y el modelo adecuados (Tab, Cmd+K, Agent).
3. Para tareas en la nube, los agentes siguen [AGENTS.md](AGENTS.md).
